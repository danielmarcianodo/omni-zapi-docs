O [SDK de conexão de canais](/channels/connect-channel) ([`@omnizapi/connect`](https://www.npmjs.com/package/@omnizapi/connect)) abre o fluxo de conexão dentro do seu sistema usando a Public Key. Para evitar que ele seja usado em sites de terceiros, o {projectName} só abre o SDK nos domínios que você autorizar.

## Cadastrar os domínios

1. No painel, abra [Segurança](https://app.omni.z-api.io/app/security).
2. Abra a aba **Configurações da SDK** e, em **Domínios autorizados**, informe o domínio onde o SDK será usado (por exemplo, `app.suaempresa.com.br`).
3. Clique em **Adicionar** e repita para cada domínio.
4. Clique em **Salvar alterações**.

## Regras

Cada entrada libera os sites assim:

| Entrada | Libera |
|---|---|
| `https://app.suaempresa.com.br` | Só essa origem |
| `https://*.suaempresa.com.br` | Qualquer subdomínio, com o mesmo protocolo e a mesma porta. Não libera `suaempresa.com.br` nem domínios parecidos, como `outrasuaempresa.com.br` ou `suaempresa.com.br.outro.com` |
| `app.suaempresa.com.br` ou `*.suaempresa.com.br` | O mesmo que com `https://` |

- O curinga `*` só vale como o primeiro trecho inteiro do domínio: `*`, `*.com.br` e `a*.suaempresa.com.br` não liberam nada.
- Entrada com usuário ou senha (`usuario@host`) é recusada.
- Curinga e entrada sem `https://` exigem o `@omnizapi/connect` 1.1.1 ou superior. Com versões anteriores, cadastre a origem exata, com o protocolo.
- O painel do {projectName} sempre pode abrir o SDK, mesmo que não esteja na lista.
- Cadastre também os domínios de homologação ou teste, se você usar o SDK neles.

<Note>
  A Public Key pode ficar no frontend porque só permite conectar canais. Mesmo assim, cadastre os domínios: é isso que impede outro site de usar a sua Public Key.
</Note>
