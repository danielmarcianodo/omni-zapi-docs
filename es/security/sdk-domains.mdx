El [SDK de conexión de canales](/es/channels/connect-channel) ([`@omnizapi/connect`](https://www.npmjs.com/package/@omnizapi/connect)) abre el flujo de conexión dentro de tu sistema usando la Public Key. Para evitar que se use en sitios de terceros, {projectName} solo abre el SDK en los dominios que autorices.

## Registrar los dominios

1. En el panel, abre [Seguridad](https://app.omni.z-api.io/app/security).
2. Abre la pestaña **Configuración del SDK** y, en **Dominios autorizados**, ingresa el dominio donde se usará el SDK (por ejemplo, `app.tuempresa.com`).
3. Haz clic en **Agregar** y repite para cada dominio.
4. Haz clic en **Guardar los cambios**.

## Reglas

Cada entrada habilita los sitios así:

| Entrada | Habilita |
|---|---|
| `https://app.tuempresa.com` | Solo ese origen |
| `https://*.tuempresa.com` | Cualquier subdominio, con el mismo protocolo y el mismo puerto. No habilita `tuempresa.com` ni dominios parecidos, como `otratuempresa.com` o `tuempresa.com.otro.com` |
| `app.tuempresa.com` o `*.tuempresa.com` | Lo mismo que con `https://` |

- El comodín `*` solo vale como el primer tramo completo del dominio: `*`, `*.com` y `a*.tuempresa.com` no habilitan nada.
- Una entrada con usuario o contraseña (`usuario@host`) se rechaza.
- El comodín y las entradas sin `https://` requieren `@omnizapi/connect` 1.1.1 o superior. Con versiones anteriores, registra el origen exacto, con el protocolo.
- El panel de {projectName} siempre puede abrir el SDK, aunque no esté en la lista.
- Registra también tus dominios de pruebas si usas el SDK en ellos.

<Note>
  La Public Key puede quedar en el frontend porque solo permite conectar canales. Aun así, registra los dominios: eso es lo que impide que otro sitio use tu Public Key.
</Note>
