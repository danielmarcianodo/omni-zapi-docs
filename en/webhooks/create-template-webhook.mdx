## Overview

Creates a template webhook. It does not depend on an instance — the `instanceId` is stored as `null` automatically — and receives only WhatsApp template events.

The `events` field accepts **only** `UPDATE_TEMPLATE_STATUS`, `UPDATE_TEMPLATE_CATEGORY` and `CHANNEL_DISCONNECTED`. A channel event results in `422`.

<Note>
  `CHANNEL_DISCONNECTED` is being rolled out. Until it is released for your account, a request that includes it returns `422 {"error":"Platform events are not available yet"}` and nothing is saved. See [Channel disconnection notice](/en/webhooks/channel-disconnected).
</Note>

### `payloadFormat` is ignored

For template webhooks the format is always `DEFAULT`. You may omit the field; if sent (any value), it is silently discarded and persisted as `DEFAULT`.

### HMAC signing

If `signing: true`, the `secret` field is generated and returned **only in this response**. Store it securely — it will not be shown again.

The signature arrives in the `x-webhook-signature` header and is computed over a canonical string of five fields — not over the body alone. See [HMAC signing](/en/webhooks/signature).
